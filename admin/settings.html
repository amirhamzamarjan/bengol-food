Database Schema & Tables

The schema file is located at supabase_schema.sql in the project root. It creates the products, bulk_orders, and site_content tables with full Row Level Security (RLS) policies.

-- 1. In Supabase Dashboard -> SQL Editor
-- 2. Open and paste `supabase_schema.sql`
-- 3. Click Run to set up tables, RLS policies, and seed products.
